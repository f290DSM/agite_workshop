## Definition of Done (DoD)

Para considerar a entrega concluida, o grupo deve cumprir:

- [ ] Landing page implementada e funcional.
- [ ] Cada aluno tem pelo menos 1 tarefa registrada no backlog.
- [ ] Cada aluno tem pelo menos 1 commit no repositorio.
- [ ] As branches seguem o padrao `feature/nome-da-tarefa-seu-nome`.
- [ ] Pull Requests foram criados para a branch `main`.
- [ ] Cada PR recebeu revisao de pelo menos 1 colega.
- [ ] Comentarios de review foram respondidos, quando existirem.
- [ ] Merges foram realizados apos aprovacao.
- [ ] Bloqueios e pendencias foram registrados.
- [ ] A landing page foi demonstrada na Sprint Review.
- [ ] A retrospectiva foi preenchida em `RETROSPECTIVE.md`.
